# How to convert exported PNG to webp on macOS
## Download script
Download <a href="https://github.com/MaxBazarov/demo-station-plugin/raw/main/docs/files/png_to_webp.sh">bash script</a>.
Move it to a parent of a folder with unzipped prototype.

## Run script in Terminal
bash png_to_webp.sh <PROTOTYPE_FOILDER>

## Webp installation
If you have no webp installed then follow the script instruction in Terminal
